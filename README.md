# Генератор документов УСБ МВД — React-приложение

Веб-приложение (React + Vite): вы описываете ситуацию в одном поле — DeepSeek определяет сценарий
документооборота, подбирает нужные документы в правильном порядке (включая Приказ) и **заполняет
поля форм**. Вы проверяете и правите любой документ, видите живой предпросмотр PDF и **скачиваете
PDF сами**. Законодательная база — обычный файл `laws.md`.

## Что нужно

- **Node.js 18+** (проверено на v22).
- **Ключ DeepSeek API** — https://platform.deepseek.com → API keys.

## Структура

| Путь | Назначение |
|------|-----------|
| `web/` | React-приложение (Vite). Исходники в `web/src`, движок PDF и шрифты — `web/public/vendor` |
| `server.js` | Локальный сервер: прокси DeepSeek (ключ скрыт), чтение `laws.md`, раздача собранного приложения |
| `laws.md` | Законодательная база (редактируете руками) |
| `config.json` | Настройки и ключ DeepSeek (из `config.example.json`) |
| `dist/` | Собранное приложение (создаётся `npm run build`) |

PDF-движок (`pdf-lib`, `fontkit`), шрифты и логика раскладки взяты из прежней версии без изменений
и подключаются как «вендорные» скрипты — PDF получается идентичным прежнему.

## Запуск — одной командой

```bash
cp config.example.json config.json   # впишите deepseek.apiKey (один раз)
npm start
```

`npm start` сам поставит зависимости, соберёт приложение (`web → dist`) и запустит сервер.
Откройте **http://localhost:3000**.

Другие команды (из корня):

| Команда | Что делает |
|---------|-----------|
| `npm start` | собрать и запустить (одной командой) |
| `npm run build` | только собрать (`npm i` + `vite build` в `web/`) |
| `npm run serve` | запустить сервер без пересборки (быстрый перезапуск) |

## Режим разработки (hot reload)

Два терминала (из корня):

```bash
npm run dev:server   # терминал 1 — API-сервер (:3000)
npm run dev:web      # терминал 2 — Vite dev (:5173, проксирует /api на :3000)
```

Откройте **http://localhost:5173**. Правки в `web/src` применяются на лету.

## Как пользоваться

1. Слева — **«🤖 Генерация по ситуации»**.
2. Опишите ситуацию (кто, что нарушил, обстоятельства, доказательства, звания, уд. №).
3. Выберите сценарий (или **Авто**):
   - **Строгач:** Акт → Уведомление → Приказ.
   - **Увольнение + проверка:** Акт (с отстранением) → Уведомление → Распоряжение → Рапорт → Приказ.
4. **«Сгенерировать пакет»** — документы появятся карточками. AI заполняет все поля (включая Приказ).
5. Откройте любой документ: правьте поля, справа — живой предпросмотр. **«Скачать PDF»** (или
   «Скачать все PDF» в пакете). Ничего не скачивается автоматически — только по вашей кнопке.

Любой документ можно открыть и вручную (список слева), как раньше.

## Законодательная база — `laws.md`

Это обычный Markdown-файл в корне проекта. Редактируйте его любым редактором: вставляйте актуальные
статьи устава, классификацию нарушений (п. 7.8), статьи УК/УПК. AI ссылается только на то, что есть
в `laws.md` (не выдумывает номера). После правок нажмите **«Перечитать laws.md»** в панели.

Большой `laws.md` целиком в контекст не отправляется: приложение отбирает релевантные разделы
(всегда — дисциплину и классификацию НВС, плюс статьи под конкретную ситуацию).

## Конфиг (`config.json`)

| Поле | Назначение |
|------|-----------|
| `port` | Порт сервера (по умолчанию 3000) |
| `deepseek.apiKey` | Ключ DeepSeek API (только на сервере, в браузер не попадает) |
| `deepseek.model` | `deepseek-chat` (по умолч.) / `deepseek-reasoner` / `deepseek-flash` |

`config.json`, `dist/`, `node_modules/` — в `.gitignore`.

> `index.legacy.html` — прежний однофайловый генератор, оставлен как запасной вариант (откройте
> двойным кликом, работает офлайн, но без AI и живого сервера). Основное приложение — в `web/`.
